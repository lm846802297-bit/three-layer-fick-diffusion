# 任意晚的捕获反超：慢模判据、三层最小性与观测幅度

## 1. 通用谱假设

设 \(x\) 为模型参数，\(x_*\) 为有限参数点，比较信号写成
\[
F_x(t)=a_0(x)+\sum_{n\ge1}a_n(x)e^{-\lambda_n(x)t},\qquad
0<\lambda_1(x)<\lambda_2(x)<\cdots .
\]
讨论任意晚的交叉时固定时间标度，不允许靠统一减慢动力学把全部时间乘上任意大的常数。假设参数邻域中各有限阶谱数据连续，有一致的本征值下界 \(\lambda_n\ge c n^\gamma\)（\(c,\gamma>0\)），以及 \(|a_n|\le C(1+\lambda_n)^p\)。这使任意有限阶时间导数可在 \(t>0\) 上逐项取，同时有限阶谱隙在足够小邻域内有正下界。三层等 Robin Fick 模型满足这些假设：来自 Sturm 简单谱、min–max 比较及本征函数迹界。

在以下定理中，反超指导致领先方换手的严格变号零点。上界实际适用于不同零点的计数，包括相切。

## 2. 必要性与局部充分性

**必要性。** 若存在 \(x_k\to x_*\)，其每条曲线在 \(t\ge T_k\to\infty\) 都有至少 \(m\) 个不同零点，则
\[
a_0(x_*)=a_1(x_*)=\cdots=a_{m-1}(x_*)=0.
\]

事实上，若 \(a_0(x_*)\ne0\)，在邻域内从某一共同迟时起信号与 \(a_0\) 同号。若第一个非零量为 \(a_j(x_*)\)（\(1\le j<m\)），令 \(\lambda_0=0\)，并作用
\[
P_j=\prod_{\ell=0}^{j-1}(\partial_t+\lambda_\ell(x))
\]
于 \(F_x\)。最低未被消掉的项为
\(a_j\prod_{\ell<j}(\lambda_\ell-\lambda_j)e^{-\lambda_jt}\)。其系数在足够小邻域内与零有正距离，归一化高阶余项从某一共同迟时起小于其绝对值。这个一致性可把前有限项用连续谱隙控制，后无限项用一致本征值下界及多项式界控制。故 \(P_jF_x\) 在该时间窗里不变号且没有零点。每个因子等于先乘一个正指数、求导、再除以该指数；Rolle 定理给 \(F_x\) 在这个时间窗里至多 \(j\) 个不同零点，矛盾。

**局部充分性。** 若 \(a_0=\cdots=a_{m-1}=0\)、\(a_m(x_*)\ne0\)，且 \(x\mapsto(a_0,\ldots,a_{m-1})\) 在 \(x_*\) 为 \(C^1\) 满秩映射，低阶本征值在附近局部 Lipschitz，则存在 \(x_T\to x_*\)，使 \(m\) 次严格反超都出现在任意给定截止以后。更精确地，对给定的 \(m\) 个不同偏移量 \(\tau_i\)，可使第 \(i\) 个迟时零点为 \(T+\tau_i+o(1)\)。

证明：满秩给 \(C^1\) 局部截面。固定临界谱 \(\lambda_j^*=\lambda_j(x_*)\)，对 \(j<m\) 取 \(a_j(x_T)=b_j e^{-(\lambda_m^*-\lambda_j^*)T}\)。最小谱隙为正，所以 \(x_T-x_*\) 指数小，\((\lambda_j(x_T)-\lambda_j^*)T\to0\)。在每个有界 \(\tau\) 窗口，缩放曲线在 \(C^1\) 中趋于
\[
e^{\lambda_m^* T}F_{x_T}(T+\tau)\longrightarrow
G(\tau)=\sum_{j<m}b_j e^{-\lambda_j^*\tau}+a_m(x_*)e^{-\lambda_m^*\tau}.
\]
这里后续谱项的一致消失由相同谱尾估计给出。用前 \(m\) 个指数函数插值，令 \(G(\tau_i)=0\)。插值可逆，因为非零的 \(m\) 项实指数和至多 \(m-1\) 个实零点（按重数计，通过除正指数并反复使用 Rolle 证明）。全 \(m+1\) 项的 \(G\) 恰有规定的 \(m\) 个单根。\(C^1\) 收敛保持每处严格变号及单根。将上一段的加权导数论证用到 \(j=m\)，可知在邻域内有一个共同晚期门槛，此后至多 \(m\) 个零点，所以构造恰有 \(m\) 个晚根。该结论不计门槛之前的交叉；已验证三层算例的早期严格同号来自独立区间证书。

## 3. 两层限制：包括趋近均匀，以及层宽趋近零

在单位区间的模型中固定中点源、界面理想、壁面反应性相同。将界面在中点右侧的情况整体反射后，只需考虑左壁层宽 \(h\in[0,\tfrac12]\)，扩散系数 \(D\)，其余区间系数归一为 1。用未归一化物理时间时等价于除以参考层 \(D_R\) 的时间单位，同时壁面参数变为 \(\kappa/D_R\)。以下的紧参数条件是归一化后 \(D\) 和 \(\kappa\) 均有正下界和有限上界，不要求 \(h\) 或 \(|D-1|\) 有正下界。令 \(\Delta=A_L-A_R\)。

**结论：** 在上述任一紧参数范围内，存在与 \(h\) 和扩散对比度无关的共同时间上界 \(T_0\)。所有非均匀样品在 \(t\ge T_0\) 都保持最终的领先方向，不可能有任意晚的反超。均匀或消失层样品则两侧恒等，不能把恒等零当作反超。

证明。静态阻力公式给
\[
 d=\Delta_\infty=\frac{h(1-1/D)}{1+2/\kappa+h(1/D-1)}.
\]
因此 \(|d|\ge c_0h|D-1|\)（某个正的统一常数）。仅用这条式子不足，因为 \(h\to0\) 或 \(D\to1\) 时 \(d\) 会变小；需同时控制瞬态。

用 \(k_n=\sqrt{\lambda_n}\) 以及初始状态 \((y,D(x)y'/k)=(1,\kappa/k)\) 定义左归一本征解。令 \(F(k)=p(1)+\kappa y(1)/k\)，其中 \(p=D(x)y'/k\)。记 \(N_n=\int_0^1 y_n^2\,dx\)。在本征根上，拉格朗日恒等式给
\[
 F_k(k_n)=-2N_n/y_n(1).
\]
具体而言，先用实际通量 \(q=D(x)y'\)，对 \(\lambda=k^2\) 微分并积分
\((y\,\partial_\lambda q-q\,\partial_\lambda y)'=-y^2\)；初端微分为零，末端代入 \(q(1)=-\kappa y(1)\)。\(F\) 为实际末端残差除以 \(k\)，所以在残差零点给上述式子。

在紧参数块中，Robin min–max 给 \(k_n\asymp n\)（有限低模的 \(k_n\) 也统一离零）。缩放通量的传递矩阵及其逆在实 \(k\) 上一致有界，因为矩阵元只是有界的正余弦乘以 \(\sqrt D\) 或 \(1/\sqrt D\)。于是 \(y_n(1)\) 上界统一，且中点状态整体大小有统一正下界。右半段的 \(y=a\cos kx+b\sin kx\) 给 \(N_n\ge (1/4-1/(2k_n))(a^2+b^2)\)（大 \(k_n\)）；剩余有限模由连续性和正性得到下界。因此 \(|F_k(k_n)|\) 一致离零。固定顺序的矩阵乘积、初值、归一化积分及它们在 \(h,D,k\) 的任意固定阶偏导至多按 \(k\) 的幂增长，对 \([0,1/2]\) 的边点使用单侧导数。隐函数微分随即给 \(k_n\) 的 \(h,D\) 一阶和混合二阶导数的多项式界，分母仅含这些有正下界的因子。

令瞬态展开为 \(\Delta=d-\sum c_n e^{-k_n^2t}\)，其中
\(c_n=\kappa y_n(1/2)(1-y_n(1))/(k_n^2 N_n)\)。同一估计给 \(\sup|\partial_h\partial_D c_n|\le C(1+n)^P\)。当 \(D=1\) 或 \(h=0\)，均匀器件的每一模或在中点为零、或两壁值相等，故各 \(c_n\) 精确为零。在 \(h,D\) 上两次积分，
\[
 |c_n|\le C(1+n)^P h|D-1|.
\]
把紧参数块适当扩大以包含 \(D=1\)，上界仍有效。最后
\[
 \frac{|\Delta(t)-d|}{|d|}\le \frac{C}{c_0}\sum_{n\ge1}(1+n)^P e^{-b n^2t}
 \longrightarrow 0
\]
一致成立（\(b>0\)）。选使右端小于 1 的共同 \(T_0\)，即证。

因此，在固定中点、等壁面反应性、理想界面且材料参数保持有限正值的非退化框架内，**三层是实现三次任意晚反超的最小层数**。一层恒等，两层无法产生任意晚的反超，三层已构造。该结论不宣称两层永无有限时间反超，不覆盖逃向反射边界或材料系数奇异的非紧序列，也不限制整个三层族的总穿越次数。

## 4. 可分辨幅度

在三层算例 \(\lambda_1^*\simeq7.18405,\lambda_2^*\simeq26.03766,\lambda_3^*\simeq56.13801\)。对离目标零点固定距离的符号见证时刻，绝对累计差按 \(e^{-\lambda_3^*T}\) 缩小。尚未捕获质量在附近由正的基态贡献主导，故以尚存质量归一后仍按 \(e^{-(\lambda_3^*-\lambda_1^*)T}\) 缩小。零点本身当然为零；这些尺度描述的是零点之间的可分辨信号。80 位高精度示意（24 模，非区间证书）把三个零点安排在 \(T+\{0.02,0.04,0.06\}\) 附近：

| 无量纲平移量 \(T\) | \(\left|\Delta(T+0.03)\right|\) | 除以基态近似存活量 |
|---:|---:|---:|
| 0.25 | \(5.10\times10^{-11}\) | \(2.99\times10^{-10}\) |
| 0.50 | \(4.54\times10^{-17}\) | \(1.60\times10^{-15}\) |
| 1.00 | \(2.93\times10^{-29}\) | \(3.76\times10^{-26}\) |
| 2.00 | \(1.22\times10^{-53}\) | \(2.06\times10^{-47}\) |

此表仅展示该构造的幅度代价，不把数值误差视为证书，也不是实际探测器的检出限。复算：python late_amplitude.py；同目录 late_triple.py 给临界点的区间认证。三层谱证书的物理设定与证明见 LATE_TRIPLE.md、EXACTLY_THREE.md。
