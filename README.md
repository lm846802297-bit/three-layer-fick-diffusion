# Three-Layer Fick Diffusion

This repository studies changes in cumulative capture order at two equally reactive Robin walls in a one-dimensional three-layer medium.

- [Research index and reproduction instructions (中文)](research/INDEX.md)
- [Follow-up proofs and certificates (中文)](research/FOLLOWUP_INDEX.md)
- [Exact three-crossing benchmark](research/EXACTLY_THREE.md)
- [Three crossings beyond any prescribed observation time](research/LATE_TRIPLE.md)
- [Critical-branch exploration](research/CRITICAL_BRANCH.md)

The exact crossing count is established locally for specified benchmarks. No global upper bound for the full three-layer family is claimed. This snapshot distinguishes interval-certified results from exploratory floating-point work.
