# 用实际半谱与全谱封闭早时门槛：次负谷排除证书

这一节不试图由原始卷积输入的单谷形状直接推回物理模型。它用[早时门槛](FIRST_INVERSION_POSITIVE_TIME_GATES.md)给出一个依赖半谱的严格接合时间，再由**同一个扩散算子**的全谱及留数控制该时间之后的符号。这里 \(d>0\) 为左壁最终占优，\(a=L_1<b=R_1\) 为唯一的半谱逆序，\(\Delta=A_L-A_R=d-\sum c_n e^{-\lambda_n t}\)，\(J=(D_t+\lambda_1)\Delta\)。

## 1. 半谱门槛与全谱斜率的接合判据

使用早时门槛 \(T_+\)：其之前 \(J\) 至多向下过零一次，不可能由负转正。它可以从半谱低模及均匀右半区的倒数谱和求得：
\[
 \gamma a/b<1-bU(1-a/b),\quad
 F_+=\tfrac12[1+aU+\sqrt{(1+aU)^2-4aU\gamma}],\quad
 T_+\ge R_2^{-1}\log[(1-R_2/L_2)/(1-F_+)] .
\]
式中 \(\gamma=A_L(\infty)/A_R(\infty)\)，\(U=\sum_{n\ge2}1/R_n\)。下界公式需 \(L_2>R_2\) 且右侧为正。更一般也可以直接用真实等待分布 \(F\) 的 \(F(T_+)=F_+\) 定义。

取任意 \(0<T<T_+\)，定义
\[
 W(t)=e^{\lambda_2t}J'(t),\qquad
 e^{(\lambda_3-\lambda_2)t} W'(t)
 =\lambda_3(\lambda_3-\lambda_1)(\lambda_3-\lambda_2)c_3
 +\sum_{n\ge4}\lambda_n(\lambda_n-\lambda_1)(\lambda_n-\lambda_2)c_n
 e^{-(\lambda_n-\lambda_3)t}.
\]
如果第 3 全模正系数大于在 \(T\) 处所有后续负系数项的绝对值和，则 \(W'(t)>0\) 对 \(t\ge T\) 成立：丢弃非负高阶项，剩余扣减项在晚时绝对值只会减小。这仅要求一次尺度比较，既不逐点扫时间，也不假定全部高阶谱系数同号。

于是 \(J'\) 在 \(t\ge T\) 至多由负转正一次；\(J\) 在这部分先下降、后上升（可省略某一段）。联立前段，只可能有一个由负值构成的区间被严格正值隔开意义下的“负谷”。说明：若 \(J(T)<0\)，早段若已进入负区，晚段只能结束它，不能再进一次；若 \(J(T)\ge0\)，早段不可能曾严格负又回正（接合点也位于严格早段内部），晚段至多进出一次。结合
\[
 (e^{\lambda_1t}\Delta)'=e^{\lambda_1t}J(t)
\]
和初值为零、最终 \(d>0\)，乘权累计差只可能经历一次下降阶段，因而实际累计捕获差 \(\Delta\) **至多严格反超两次**。这里不把 \(J\) 的零点视为物理反超。

## 2. 连续参数盒证书

固定三层扩散率 \((2500,1/4,1)\)，厚度 \((0.38,0.12,0.50)\)，共同 Robin 反应性在闭区间 \(\kappa\in[1.5,5.35]\) 上。这个几何是已有有限折叠算例所在的切片，但不是只验算该折叠的极窄邻域。

- \(d>0\) 由静态阻力直接决定；左光学长度 \(0.2476<0.5\)。前两根用连续左相位比较建界；\(n\ge3\) 由 \(5(0.5-0.2476)>1\) 的光学相位差统一保证正常。
- 以有理数划分 Robin 参数盒。二次型关于 \(\kappa\) 单调，用两个端点上严格求根括区夹住盒内的全谱；在两端根括区对每个传递解的节点数验证模态编号。浮点仅提议根括区；正负、节点数与门槛全部用有向区间确定。
- 从向内传播的状态 \((y,Dy'/k)\) 求每层振幅及该层精确平方范数，由 \(c_n=\kappa\,y(1/2)(1-y(1))/(\lambda_n\|y\|_2^2)\) 求实际带符号系数。
- 对未显式保留的全谱尾，Robin min–max 给 \(\lambda_n\ge D_{\min}\pi^2(n-1)^2>2(n-1)^2\)（\(n\ge2\)）。归一化本征函数的迹界 \(\|\phi_n\|_\infty^2\le1+4\sqrt{\lambda_n}\) 来自平方函数的一维积分及能量界。据此 \(|c_n|\lambda_n(\lambda_n-\lambda_1)(\lambda_n-\lambda_2)\le10\kappa\lambda_n^{5/2}\) 对高谱成立。选保留 24 模使 \(x^{5/2}e^{-Tx}\) 在遗漏谱段严格下降。再用相邻上界的几何比给**整个无穷尾**，不是设为零。

复算：

```bash
python fick_middle_curvature_certificate.py 1500 3000 20
python fick_middle_curvature_certificate.py 3000 5350 20
```

参数单位为 (10^{-3})。两轮分别通过 224 和 401 个连续参数盒，未留下未覆盖盒；归一化斜率的最小认证下界分别大于 4130.34 和 8.88。认证器遇到区间依赖误差会细分参数盒，并对任何无法覆盖的盒明确失败。全部不等式有严格裕量，且半谱高模相位界与全谱尾界保留统一裕量。因此连续性也给该紧切片在完整几何参数空间中的一个开邻域，虽然本次没有量化其宽度。

这证明的是固定几何上的连续参数子域及一个适用其它几何的可检验充分判据。远离此子域，可能是半谱门槛过早，也可能是第 3 模不能压过后续负项；单独不通过其中一项都不能作为第二负谷的反例。整个三层模型的上限仍未证明。
